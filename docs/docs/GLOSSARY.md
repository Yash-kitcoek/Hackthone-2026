# Glossary

| Term | Meaning |
|---|---|
| ASN | Autonomous system number |
| Beaconing | Regular, periodic outbound check-ins (e.g. malware to C2) |
| C2 | Command and control |
| Data diode | Hardware enforcing one-way data flow |
| DDoS | Distributed denial of service |
| DGA | Domain generation algorithm |
| DNS tunnelling | Smuggling data inside DNS queries/responses |
| Entropy | Randomness measure of a string/distribution |
| Exfiltration | Unauthorised data transfer out |
| Flow | Packets sharing 5-tuple within a time window |
| Fan-out | Number of distinct destinations a source contacts |
| IAT | Inter-arrival time |
| JA3/JA4 | TLS client fingerprinting methods |
| NDR / IDS | Network detection and response / intrusion detection system |
| PCAP | Packet capture file |
| QUIC | UDP-based encrypted transport |
| SPAN | Switch port mirroring |
| TAP | Hardware traffic copier |
| Unidirectional | One observable direction only |
